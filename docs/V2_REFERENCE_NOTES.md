# 두 추가 참고 자료의 적용 범위

확인일: 2026-11-03. 결과에 따른 프롬프트 수정이 아니라 이론·해석 범위의 기록이다.

## Native neuron의 해석 가능성과 설명자의 견고성

[Cammarata, Neural Networks Are Already Clean (Goodfire, 2026)](https://already-clean.goodfire.com/)는 원래 뉴런과 연결을 직접 연구하는 관점을 제시한 작업 가설이다. v2는 뉴런이 의미적으로 clean한 비율을 추정하거나 그 주장을 반증하는 실험이 아니다. 정답을 계산할 수 있는 원래 부분 회로에서, 외부 설명자의 관측·계산 선택을 검사한다.

양의 스케일 s에 대해 본 편집은 `h_i(x)=GELU(g_i x)*(u_i x)`를 `s*h_i(x)`로, write vector `d_i`를 `d_i/s`로 바꾼다. 따라서:

- 모든 x에서 해당 뉴런의 residual 기여 `d_i*h_i(x)`가 실수 연산상 같다.
- 개별 뉴런의 활성화 부호와 입력 문맥 사이의 순위는 같다. 서로 다른 뉴런 사이의 절대 활성화 크기 순위는 바뀔 수 있다.
- write vector의 단위 방향 `d_i/||d_i||`는 같다.
- gate, `d_i*u_i`, 전체 함수는 같다.

즉, 이런 편집에서 설명이 달라진다면 원래 뉴런이 다른 개념을 학습했다는 결론이 아니다. 설명자가 같은 계산을 다르게 표현한 숫자를 읽는 방식에 관한 결과다. 이는 native neuron의 구조가 이해 가능하다는 주장과 양립할 수 있다.

## neuron-map 참고 저장소

[Ryou Jiho의 Gemma 4 E2B neuron map](https://github.com/salixkoreensis94-spec/gemma4-e2b-neuron-map/tree/99208d583f88417738c36295b4a368b63dbe8f33)의 README와 METHODS를 확인했다. 고정 revision은 `99208d583f88417738c36295b4a368b63dbe8f33`이다. 정적 write lens, 문맥에서의 측정, 생성 개입의 효과를 구분하는 방법론을 참고했다. 모델/양자화/구조가 달라 뉴런 번호나 의미 라벨을 이식하지 않았다.

특히 단위 write 방향을 읽는 분석은 본 양의 스케일 편집에 원리적으로 견고할 수 있다. 따라서 그 저장소의 지도가 본 공격에 취약하다고 주장하지 않는다. RMSNorm의 epsilon을 포함한 실제 lens 수치까지 완전히 동일하다고 가정하지도 않는다. v2에서 관찰하는 것은 비정규화된 gate/up/down 증거를 받은 별도 설명자의 판단이다.

원본 코드·벡터·문맥 데이터를 복사하지 않았으므로 제3자 자료를 새 실험 결과처럼 배포하지 않는다. 이 문서는 방법론 참고와 수학적 적용 범위이며 해당 저장소의 실험을 재현했다는 보고서가 아니다.
